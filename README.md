# 莫等闲

「莫等闲，白了少年头，空悲切。」——岳飞《满江红》

一个极简的待办清单：写下要做的事和预计完成时间，做完打勾，延期会标红提醒，每件事后面跟着一句古人关于「别拖」的话。

零依赖的小网页，可以「安装」到电脑桌面或手机桌面当 App 用，也可以把链接发给别人——**别人的数据存在别人手机上，不会到你这里来**。

## 里面有什么

```
index.html            应用本体（界面、逻辑、100 条名言都在里面）
manifest.webmanifest  让浏览器知道这是个可安装的 App
sw.js                 Service Worker：装到桌面后可离线打开
icons/                桌面图标（192 / 512 / maskable / iOS 用）
```

## 怎么用

### 手机上（推荐）

**同一个链接，电脑和手机都能装**，不用另外打包 APK。

安卓（Chrome / Edge / 三星浏览器）：

1. 浏览器打开链接。
2. 页面中间会出现 **「安装到手机桌面」** 按钮，点一下 → 确认「安装」。
3. 手机桌面就有「莫等闲」图标了（部分安卓还会出现在应用列表里），点开是全屏、没有地址栏。
4. 找不到按钮就点浏览器菜单：`⋮` → 「安装应用」或「添加到主屏幕」。

iPhone（必须用 Safari）：

1. Safari 打开链接，页面顶部会有一句提示。
2. 点底部中间的 **分享按钮**（方框 + 向上箭头）→ 往下滑找到 **「添加到主屏幕」** → 添加。
3. 桌面出现图标，点开即全屏。

> iPhone 上没有「安装」按钮——苹果不给网页这个权限，只能用「添加到主屏幕」，效果一样。
>
> 微信里打开会先提示：点右上角 `···` 选「在浏览器打开」，再按上面的步骤装。

装好之后：断网也能看已有任务；数据仍然只存在这台手机上。

### 电脑上

双击 `index.html` 用 Edge / Chrome 打开就能用。注意：`file://` 双击打开时不能「安装到桌面」，也没有离线缓存，用链接打开才有这些。

## 怎么发给别人

把**链接**发给他，和你自己用的是同一个页面：

- 他没有账号、你不用给他建任何东西；
- 他新打开时是空清单，他的任务存在他自己的浏览器里，你看不到，也影响不到你；
- 他也可以自己把它装到他的桌面/手机桌面。

这是有意设计的：不收集数据，就没有隐私和服务器成本问题。代价是——**数据不跟人走**：同一个人换手机、换浏览器，清单不会自动跟过去（后面可以加导出/导入或云同步）。

## 怎么用

- 顶上一排四个分区：**全部 / 今日 / 明日 / 延期**，旁边的数字是各有几件事。默认停在「全部」，点一下就切，重开还记得上次停在哪。
  - **全部**：按时间分组（已延期 → 今天 → 明天 → 以后 → 无截止时间）。
  - **今日**：今天到期的 + 已经过期的，过期的排在最前、拖得最久的在最上面。
  - **明日**：只有明天到期的。
  - **延期**：所有过期的，拖得越久越靠前。
  - 没有截止时间的任务只出现在「全部」里。在「今日 / 明日」里新建任务，日期会自动填好那一天；填了日期不填时间，就当「那天结束前做完」，卡片上只显示「今天」或「明天」。
- 点底部 **＋ 新任务**，填「要做的事」，可以再填日期、时间和备注。只有标题是必填的。
- **优先级**：无 / 低 / 中 / 高，点一下选中的那格。只在分组内部起作用——同一组里优先级高的排前面，不同组之间仍然按时间分（已延期永远在最上面）。
- **重复**：每天 / 每周 / 每月。选重复就必须填日期（时间可空），否则保存按钮是灰的。勾完一件，会自动生成下一次——按你原来的时间往后推，一直推到「晚于现在」为止（所以隔了三天才勾的每日任务，下一次在今天之后的同一时刻）。每月重复遇到 31 号会自动收成当月最后一天（1/31 → 2/28），不会跳到下个月去。
- 卡片上会显示 `高` `低` 这样的小标签和 `↻ 每天` 这样的重复标记；没设优先级、不重复就不显示，界面保持干净。
- 点卡片上的圆圈 → 标记完成，移入下方「已完成」。点错了展开「已完成」，点右边的 `↺` 恢复。
- 点卡片标题 → 修改内容。
- 点卡片右上角 `×` → 删除。**3 秒内**点右下角「撤销」可以反悔，连续删几条都能逐条撤销。
- 超过预计完成时间的任务：卡片左边变红、时间显示「已延期 X 天 X 小时」，页面顶部出现红色横幅「有 N 件事已延期，最久的拖了 X 天」。
- **逾期会升级**：拖得越久，卡片越刺眼——不到 3 天只是红边；3 天起加粗边框；一周起整张卡片变成红底；两周起步更重。同时这句话会换成更毒舌的版本（「这不是待办，这是纪念碑」），拖得越久越难听。
- 24 小时内到期的任务是琥珀色边，不算延期。
- **「全部」里按时间分组**：已延期 → 今天 → 明天 → 以后 → 无截止时间，每组右上角有件数，空组不显示。
- 每张卡片有一句固定的名言，创建时分配，之后不会变；只有逾期后才会按等级换成毒舌版的几句之一。顶部「今日一句」每天换一次。
- 深色模式跟着系统走。
- **勾掉一件事的瞬间**：屏幕下方会弹一句短反馈（「做完了」「这件翻篇了」之类），约 1.5 秒后自己消失，不挡操作。连着做几件，文案不会重复。
- **连续天数**：页头右上角有个「连续 N 天」的小徽章，记的是"连续有完成记录的天数"。今天还没做但昨天做了，徽章不会掉；断一天就归零，重新开始。3 / 7 / 14 / 30 / 60 / 100 天时反馈会升级成里程碑文案，刷新个人纪录时会说明。
- 撤销（已完成里的 `↺`）会把那一天的计数扣回去——撤销 3 天前完成的任务，扣的是那天的，不影响今天。

## 数据存在哪

存在浏览器的 `localStorage` 里（任务 `mdx.tasks.v1`，设置 `mdx.settings.v1`，完成统计 `mdx.stats.v1`），也就是**这台设备、这个浏览器**。

- `mdx.stats.v1` 只存"每天完成了几件"（`{days:{'2026-11-16':2}, best:7}`），最多保留最近 400 天，不存具体做了什么事。
- 清除「莫等闲」的数据会把连续天数一起清掉；只是想重装 App 的话，数据在浏览器里，不会丢。

- 换浏览器、换设备看不到同一份清单。
- 清除浏览器数据 / 用无痕模式，任务会丢。
- 用 `file://` 双击打开和用链接打开，是**两份不同的数据**（浏览器把本地文件和服务地址当成两个网站），别混着用。固定一种方式用。
- 上次停在哪个分区记在 `mdx.settings.v1` 的 `tab` 字段里；只填了日期没填时间的任务会多存一个 `dateOnly: true`（时间是当天 23:59），界面只显示「今天 / 明天」不显示钟点。

## 自己托管

PWA 的「安装到桌面」和离线缓存要求页面走 **https**（或 `localhost`）。三种可选：

### 1. 发给别人用：Cloudflare Pages（免费，不用装东西）

1. 打开 <https://dash.cloudflare.com/> 注册/登录。
2. 左边 **Workers & Pages** → **Create** → **Pages** → **Upload assets**。
3. 项目名随便起（比如 `mdx`），把 `D:\莫等闲` 里的 `index.html`、`manifest.webmanifest`、`sw.js` 和 `icons` 文件夹**一起拖进去**（`README.md` 不用传），点 Deploy。
4. 拿到 `https://mdx.pages.dev` 这样的地址，发给谁都能用。

国内访问 `*.pages.dev` 有时慢；不稳定的话可以换成 Vercel、Netlify，或者放在自己有域名的服务器上——**全是静态文件，放哪都行**。

### 2. 只在同一个 Wi-Fi 里试

```
cd /d D:\莫等闲
python -m http.server 8123
```

手机访问 `http://电脑的局域网IP:8123/`（`ipconfig` 里看「IPv4 地址」）。这样能用全部功能，但手机浏览器认为 `http://192.168.x.x` 不安全，一般不给安装到桌面。

### 3. 临时公网地址（想先给朋友看一眼）

装了 Node.js 后可以：

```
npx localtunnel --port 8123
```

拿到一个 `https://xxx.loca.lt` 地址，关掉命令就失效，适合临时试用。

## 改完之后怎么让老用户看到新版

`sw.js` 会缓存页面。改了 `index.html` 后：

1. 把 `sw.js` 第一行的 `CACHE = 'mdx-v6'` 改成 `'mdx-v7'`（每次改都 +1）；
2. 重新上传/部署。

老用户打开时：页面有更新会显示「有新版本，点此刷新」按钮；如果页面正好在后台，会自动刷新。手机桌面上的图标不用重装。

如果某台手机装完之后一直卡在旧页面（白屏或只有标题）：
- 先彻底关掉那个 App，再打开一次（新版 Service Worker 会在这一次生效）；
- 还不行就在浏览器里打开链接刷新一次；
- 最后手段：长按桌面图标 → 卸载，再重新安装。数据存在浏览器里，重装不会丢。

## 现在还没有的

- **延期只在打开应用时提醒**，不会在你没打开时弹通知。后台提醒需要在 PWA 通知（或原生 App）里单独做。  
- 没有云同步、没有多设备、没有账号、没有导出。
- 已完成的任务最多保留 200 条，超出自动清掉最旧的。
- 不是应用商店里那种原生 App。真要 APK，得单独搭 Android 构建环境打包。
